# Operações Aritméticos

## Operações matemáticas no Python

A linguagem Python em operações matemáticas utiliza uma ordem e um símbolo para representar sua prioridade e sua operação. A linguagem Python prioriza uma operação de acordo com as regras da matemática, portanto existe uma hierarquia de operações, em conjunto a isso a liguagem utiliza elementos específicos para representar cada operação. Para simplificar a explicação segue a hierarquia das operações:

- Operações:

    - Adição = +
    - Subtração = -
    - Multiplicação = *
    - Divisão = /
    - Potência = **
    - Divisão Inteira = //
    - Resto da Divisão = %

- Hierarquia:

    - 1° ()
    - 2° **
    - 3° * / // %
    - 4° + -

Como podemos observar as preferências inicias são de operações que estão em volto de parênteses e operações de multiplicação, isso ocorre por conta das regras matemáticas, portanto a linguagem vai seguir essa mesma regra.
